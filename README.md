# PIXL

DIY smartwatch na 0,96" OLED z czterema klawiszami, Seeed XIAO ESP32-S3 i DS3231, w języku wizualnym Mono You.

Strona projektu: https://szuszjan.github.io/pixl/ (model 3D, części, okablowanie, złożenie, flasher w przeglądarce, STL).

- `index.html`: strona
- `firmware/`: obraz firmware 2.1 + `manifest.json` dla ESP Web Tools
- `files/`: STL i CAD obudowy v7, źródła firmware
